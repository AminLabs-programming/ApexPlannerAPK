# راهنمای گرفتن APK از این پروژه با PWABuilder

این پوشه یک PWA (وانیلا جاوااسکریپت) آماده‌ست. تغییراتی که روش اعمال شده:

- **لوگوی جدید** (مثلث بنفش/آبی نئون) جایگزین شده در:
  - آیکون اپ (`icon-192.png`, `icon-512.png`, `icon-1024.png`)
  - آیکون‌های maskable برای اندروید (`icon-maskable-192.png`, `icon-maskable-512.png`)
  - `apple-touch-icon.png` و `favicon-32.png`
  - لوگوی داخل هدر برنامه (`logo.png` — استفاده‌شده در `index.html`)
  - لوگوی صفحه‌ی ورود/ثبت‌نام (`auth.js`)
- **اسکرول‌بار** به‌صورت کامل مخفی شده (`scrollbar-width:none` + `::-webkit-scrollbar{display:none}` روی همه‌ی المان‌ها). داخل اپ نیتیو اصلاً اسکرول‌بار نمایش داده نمی‌شه؛ در نتیجه بحث «راست یا چپ بودن»ش هم منتفیه.
- **رفتار نیتیو**: `overscroll-behavior:none` (جلوگیری از پرش صفحه)، غیرفعال شدن انتخاب متن و منوی لمس‌طولانی روی عناصر غیر ورودی (برای حس نیتیو، نه وب).
- `manifest.json`: `display_override` فقط روی `standalone` تنظیم شده تا PWABuilder هیچ‌جوره UI مرورگر/نوار آدرس رو نسازه.

## مراحل ساخت APK (بدون نیاز به Android Studio)

1. تمام محتوای همین پوشه رو (همه‌ی فایل‌ها، همراه با پوشه‌ی `well-known`) آپلود کن روی یک هاست استاتیک HTTPS — همونی که از قبل داشتی (مثلاً همون سرویس فرانت روی Railway، یا GitHub Pages).
   > ⚠️ فقط همین پوشه رو آپلود کن (فرانت‌اند). فایل `config.js` از قبل به آدرس بکندت (`apexplannerbackend-production.up.railway.app`) اشاره می‌کنه — اگه آدرس بکندت عوض شده، همون‌جا اصلاحش کن.
2. برو به [pwabuilder.com](https://www.pwabuilder.com) و آدرس دامنه‌ی همون فرانت‌اند رو وارد کن.
3. PWABuilder منیفست و آیکون‌ها رو خودکار می‌خونه (چون همه‌چی از قبل درست تنظیم شده). روی گزینه‌ی **Android** بزن.
4. توی تنظیمات پکیج اندروید:
   - **Package ID** رو انتخاب کن (مثلاً `com.apexplanner.app`).
   - **Signing key**: بذار PWABuilder خودش یک کلید جدید بسازه (Generate new)، یا کلید قبلی‌ت رو آپلود کن.
   - حتماً گزینه‌ی «Display mode: standalone» انتخاب شده باشه (پیش‌فرضه).
5. دانلود کن. داخل zip یک فایل `assetlinks.json` هست.
6. این فایل رو دقیقاً توی مسیر زیر روی همون دامنه‌ی فرانت‌اندت آپلود کن:
   ```
   https://دامنه‌ی-فرانت‌اند-تو/.well-known/assetlinks.json
   ```
   (پوشه‌ی `well-known` همین‌جا توی پروژه از قبل ساخته شده؛ کافیه فایل `assetlinks.json` رو داخلش بذاری و دوباره آپلود/دیپلوی کنی.)
7. چک کن آدرس بالا توی مرورگر باز میشه و JSON رو نشون می‌ده.
8. فایل `.apk` (یا `.aab` برای گوگل‌پلی) که PWABuilder داد رو نصب کن.

بعد از تأیید Digital Asset Links (که ممکنه چند ساعت طول بکشه تا گوگل کش کنه)، اپ کاملاً بدون نوار آدرس و بدون هیچ المان مرورگری باز میشه — دقیقاً مثل یک اپ نیتیو.

## نکته‌ی مهم درباره‌ی به‌روزرسانی‌های بعدی
اگه بعداً دوباره از PWABuilder با Package ID و کلید امضای متفاوت خروجی گرفتی، باید `assetlinks.json` رو با نسخه‌ی جدید جایگزین کنی، وگرنه نوار آدرس دوباره برمی‌گرده.
